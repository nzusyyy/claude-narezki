# AdClipper

Telegram-бот (Telethon/MTProto, файлы до 2 ГБ): YouTube → вырезка спонсоров (SponsorBlock) →
нарезка на части → 9:16 / ASMR снизу → баннер в середину → поштучная отправка.

## Запуск
1. Получи токен у @BotFather и пропиши `BOT_TOKEN` в `.env` (см. `.env.example`) или в `config.py`.
2. Windows: `start_bot.bat` · Linux: `./start.sh` · Docker: `docker compose up -d --build`

FFmpeg: `bin/ffmpeg(.exe)` → `imageio-ffmpeg` → системный. ffprobe не нужен.

## Баннер
PNG/JPG (пауза = настройка /time) или WEBM с альфой / MP4 / GIF (пауза = длина баннера, его звук сохраняется).
Баннер должен занимать ≥ 25% кадра: проверяется при загрузке и для каждой части отдельно
(с учётом пропорций кадра). Если не проходит — часть отправляется без баннера с пояснением.

## Формат кадра
Меню → 📐 Формат: **3:4 (TikTok)** — 1080×1440 (по умолчанию), 9:16 — 1080×1920, или Оригинал.
Видео вписывается с размытым фоном; если пропорции уже совпадают — не перекодируется.

## ASMR снизу
Меню → 📐 Формат → загрузить ASMR-видео. Итог в выбранном формате (3:4 → 1080×1440): твоё видео сверху, ASMR снизу — уменьшается целиком без обрезки, поля размыты (зациклено, без звука).

Используй только контент, на который у тебя есть права.

## Хостинг на Bothost
1. Тариф **Basic** (1 ГБ RAM, 5 ГБ диска) — минимум; для длинных видео лучше **Pro**. Бесплатный (256 МБ / 0.5 ГБ) не потянет.
2. Загрузи архив (zip) или Git-репозиторий, включи **«Использовать собственный Dockerfile»**.
3. В переменных окружения задай `BOT_TOKEN`. Веб-интерфейс/вебхук не включай — бот работает через MTProto.
4. В профиле включи **«Зарубежный IP»** и сделай деплой заново — так стабильнее для YouTube и SponsorBlock.
Настройки, баннеры, ASMR и сессия хранятся в `/app/data` и не теряются при передеплое.
